Model control checklist

  • Data classification: consolidated public reporting, not internal operational reporting
  • Sources: file-level origin and slide locators supplied with each row
  • Assumptions: accessible, editable, exportable, and separate from reported facts
  • Review: verify GAAP versus FTE and period-end versus average balances
  • Controls: run packaged automated tests before presenting updated datasets
  • Limitations: no user authentication, audit trail, entitlements, or regulatory certification
